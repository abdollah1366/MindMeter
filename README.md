# مایندمتر (MindMeter)

سایت تست‌های روانشناسی آنلاین به زبان فارسی — [www.MindMeter.ir](https://www.mindmeter.ir)

ساخته‌شده با **Next.js** (App Router)، **TypeScript** و **Tailwind CSS**، کاملاً راست‌چین (RTL) با فونت وزیرمتن.

## پیش‌نیازها

- [Node.js](https://nodejs.org) نسخه‌ی ۲۰ یا بالاتر (پیشنهاد: ۲۲ LTS)
- [Git](https://git-scm.com)
- [VS Code](https://code.visualstudio.com)

## اجرا در VS Code

```bash
git clone https://github.com/abdollah1366/MindMeter.git
cd MindMeter
code .
```

سپس در VS Code ترمینال را باز کنید (`` Ctrl+` ``) و بزنید:

```bash
npm install
cp .env.example .env      # در ویندوز: copy .env.example .env
npm run db:push           # ساخت پایگاه داده‌ی محلی (SQLite)
npm run db:seed           # مقاله‌های اولیه‌ی وبلاگ
npm run dev
```

> در حالت توسعه پیامکی ارسال نمی‌شود و **کد ورود همیشه `12345`** است (از `DEV_OTP_CODE` در `.env`). کد در ترمینال هم چاپ می‌شود.
> برای ارسال واقعی، `KAVENEGAR_API_KEY` و `KAVENEGAR_OTP_TEMPLATE` را در `.env` تنظیم کنید.

حالا سایت روی <http://localhost:3000> بالا می‌آید. هر تغییری در فایل‌ها بدهید، صفحه خودکار به‌روز می‌شود.

> VS Code هنگام باز کردن پروژه افزونه‌های پیشنهادی (Tailwind CSS IntelliSense و Prettier) را نشان می‌دهد؛ نصبشان کنید.

## نقش‌ها و پنل‌ها

| نقش | دسترسی |
| --- | --- |
| مراجع | انجام تست، پرونده، گزارش چاپی، اشتراک پرونده با متخصص (`/my-results`)، رزرو و پرداخت نوبت و ورود به ویزیت (`/appointments`)، درخواست مشاوره (`/referral/new`) |
| روانشناس / پزشک | پنل متخصص (`/panel`): مراجعان، گزارش‌ها و یادداشت بالینی، نوبت‌ها، ارجاع‌ها و برنامه‌ی کاری (`/panel/schedule`) |
| ادمین | پنل مدیریت (`/admin`): آمار، کاربران، تأیید متخصصان، نوبت‌ها و پرداخت‌ها، ارجاع‌ها، وبلاگ و تست‌ها |

- **ادمین شدن:** شماره‌ی موبایل خود را در `ADMIN_PHONES` در فایل `.env` بگذارید و با همان شماره وارد شوید.
- **متخصص شدن:** بعد از ورود و تکمیل اطلاعات، از `/clinician/apply` درخواست بدهید. ادمین از `/admin/clinicians` آن را تأیید می‌کند.

## تست‌های موجود

| کد | نام | سؤال | مقیاس‌ها |
| --- | --- | --- | --- |
| PHQ-9 | افسردگی | ۹ | شدت افسردگی + هشدار ایمنی |
| GAD-7 | اضطراب فراگیر | ۷ | شدت اضطراب |
| DASS-21 / DASS-42 | افسردگی، اضطراب، استرس (کوتاه/بلند) | ۲۱ / ۴۲ | ۳ مقیاس |
| K6 / K10 | پریشانی روانشناختی کسلر (کوتاه/بلند) | ۶ / ۱۰ | پریشانی |
| WHO-5 | بهزیستی روانی | ۵ | ۰ تا ۱۰۰ |
| RSES | عزت نفس روزنبرگ | ۱۰ | عزت نفس |
| Mini-IPIP / IPIP-50 | پنج عامل بزرگ شخصیت (کوتاه/بلند) | ۲۰ / ۵۰ | ۵ عامل |
| MMI-24 / MMI-108 | تست هوش مایندمتر (کوتاه/بلند، سؤال‌های اختصاصی در سه سطح، هنجار سنی و جنسی، راهنمای ارجاع به وکسلر) | ۲۴ / ۱۰۸ | تصویری، عددی، کلامی + نمره‌ی کل |

همه از ابزارهای با مجوز استفاده‌ی آزاد هستند؛ منبع و مجوز هر کدام در فایل تست و صفحه‌ی تست آمده است.
ترجمه‌ها **ترجمه‌ی کاری** هستند و پیش از انتشار باید با نسخه‌های فارسی هنجاریابی‌شده تطبیق داده و توسط روانشناس بالینی تأیید شوند.

## ثبت‌نام، پرونده و گزارش

- ورود و ثبت‌نام با شماره موبایل و کد یک‌بارمصرف (اعتبار ۲ دقیقه، محدودیت ارسال و تعداد تلاش)
- نتیجه‌ی هر تست برای کاربر واردشده در پایگاه داده ذخیره می‌شود؛ امتیاز در سرور دوباره محاسبه می‌شود
- کاربر مهمان هم می‌تواند تست بدهد و بعد از ورود نتیجه را در پرونده ذخیره کند
- گزارش رسمی قابل چاپ (`/reports/<id>`) فقط بعد از تکمیل نام، کد ملی (با اعتبارسنجی)، تاریخ تولد شمسی و جنسیت صادر می‌شود

## هنجار تست‌های هوش

- **هنجار شرکت‌کنندگان:** خودکار از نخستین نتیجه‌ی هر کاربر ساخته می‌شود. هر نتیجه با هم‌سن و هم‌جنس‌ها مقایسه می‌شود (صدک و نمره‌ی استاندارد با میانگین ۱۰۰). اگر گروه کمتر از ۳۰ نفر باشد، گروه بزرگ‌تر استفاده می‌شود.
- **هنجار داخلی:** در `/admin/norms` ثبت می‌شود؛ یا دستی از یک پژوهش هنجاریابی، یا با یک کلیک از آمار شرکت‌کنندگان وقتی گروه به ۳۰ نفر رسید.

## نوبت‌دهی و ویزیت آنلاین

1. متخصص در `/panel/schedule` تعرفه، مدت جلسه و ساعات کاری هفتگی را ثبت می‌کند.
2. مراجع در صفحه‌ی متخصص (`/clinicians/<id>`) یکی از زمان‌های خالی را انتخاب می‌کند و هزینه را می‌پردازد.
   - بدون `ZARINPAL_MERCHANT_ID` در حالت توسعه «پرداخت آزمایشی» نمایش داده می‌شود.
3. از ۱۰ دقیقه قبل از شروع، دکمه‌ی «ورود به ویزیت» در `/appointments` و `/panel/appointments` فعال می‌شود.
4. اتاق ویزیت (`/visit/<id>`) تماس تصویری مستقیم (WebRTC) است و روی `localhost` یا HTTPS کار می‌کند. برای اتصال پایدار در اینترنت ایران یک TURN server لازم است (`ICE_SERVERS` در `.env`).

## اضافه کردن تست جدید

1. یک فایل در `src/data/tests/` بسازید (از روی `gad7.ts` یا برای چندمقیاسی از `dass21.ts` کپی کنید).
2. `slug`، `code`، گزینه‌ها، سؤال‌ها، `scales` و `source` را بنویسید.
   - سؤالی که `reverse: true` دارد امتیازش معکوس حساب می‌شود؛ `scale` مشخص می‌کند سؤال به کدام مقیاس تعلق دارد.
   - برای آزمون توانایی (پاسخ درست/نادرست) `kind: "ability"` بگذارید و برای هر سؤال `answer` (مقدار گزینه‌ی درست) را مشخص کنید؛ سؤال ماتریس با `figure` ساخته می‌شود (نمونه: `intelligence-short.ts`؛ سازنده‌ی سؤال‌ها در `_intelligence.ts`). سؤال توانایی خودکار گزینه‌ی «نمی‌دانم» می‌گیرد و با `level` سطح دشواری‌اش مشخص می‌شود..
   - مقیاس ترکیبی (مثل نمره‌ی کل) با `includes` ساخته می‌شود.
   - `multiplier` برای ضریب امتیاز (مثل DASS-21) و `alert` برای هشدار ایمنی است.
   - اگر تست فرم کوتاه و بلند دارد، هر کدام فایل جدا دارد و با `version.pairSlug` به هم وصل می‌شوند.
3. آن را در `src/data/tests/index.ts` به آرایه‌ی `tests` اضافه کنید.
4. `npm run validate:tests` را اجرا کنید تا بازه‌ها و مقیاس‌ها بررسی شوند.
5. فیلد `category` باید یکی از `slug`های `src/data/categories.ts` باشد. با `featured: true` تست در صفحه‌ی اصلی هم نمایش داده می‌شود.

تست در صفحه‌ی اصلی و در آدرس `/tests/<slug>` نمایش داده می‌شود.

> ⚠️ مقاله‌های فعلی نمونه‌اند.
