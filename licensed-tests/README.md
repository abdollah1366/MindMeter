# پرسشنامه‌های دارای مجوز

برخی آزمون‌ها، مثل MMPI-3 (ناشر: انتشارات دانشگاه مینه‌سوتا / Pearson)، حق نشر دارند. سؤال‌ها، کلید نمره‌گذاری و نرم‌های آن‌ها را فقط با خرید مجوز
می‌توان اجرا کرد. مایندمتر محتوای این آزمون‌ها را ندارد، ولی موتور اجرای آن‌ها آماده است. اگر مجوز گرفتید:

1. سؤال‌ها و کلیدهای رسمی را در یک فایل `‎<slug>.json` با ساختار `example-inventory.sample.json` بنویسید و در همین پوشه روی **سرور** بگذارید.
   (مسیر دیگری هم می‌شود با متغیر `LICENSED_TESTS_DIR` در `.env` تعیین کرد.)
2. سرور را دوباره اجرا کنید (`npm run build && npm start` یا `npm run dev`).
3. با `npm run validate:tests` خطاهای فایل را ببینید. در «ادمین ← تست‌ها» هم خطاها نمایش داده می‌شود.

فایل‌های `*.json` این پوشه در `.gitignore` هستند و هرگز در گیت منتشر نمی‌شوند. فقط فایل‌های `*.sample.json` در مخزن هستند.

## نکته‌های ساختار

- `restricted` (پیش‌فرض `true`): آزمون در فهرست‌ها، جستجو و نقشه‌ی سایت نمی‌آید و فقط با لینک مستقیم و ورود قابل اجراست.
- `scaleGroups`: گروه‌های گزارش. گروهی که `"validity": true` دارد شاخص‌های اعتبار است. اگر نتیجه‌ی یکی از آن‌ها `severe` باشد، نیم‌رخ «نامعتبر» اعلام می‌شود.
- `scales[].items`: کلید صریح مقیاس، به شکل `{ "id": "۱۲", "reverse": true }`. «reverse» یعنی پاسخ «نادرست» امتیاز دارد. یک سؤال می‌تواند در چند مقیاس باشد.
- `scales[].method`:
  - `"inconsistency"` با `pairs` از نوع `same` یا `opposite`، مثل VRIN.
  - `"acquiescence"` با جفت‌های `opposite`، مثل TRIN. امتیاز آن از −n تا +n است.
- `normMetric: "T"`: نمره‌ی T (میانگین ۵۰، انحراف معیار ۱۰).
  - اگر نرم رسمی را در «ادمین ← هنجارها» وارد کنید، از همان استفاده می‌شود.
  - در غیر این صورت، وقتی دست‌کم ۳۰ نفر هم‌گروه آزمون را انجام دهند، T از داده‌ی شرکت‌کنندگان محاسبه می‌شود.
- `questions[].critical`: پاسخ کلیدی به این سؤال در گزارش متخصص زیر «پاسخ‌های نیازمند پیگیری» فهرست می‌شود.
- `questions[].alert`: پیام ایمنی فوری، مثلاً برای افکار خودکشی: `{ "minValue": 1, "message": "..." }`.
- بازه‌های `results` هر مقیاس باید کل محدوده‌ی امتیاز را بدون فاصله بپوشانند.
